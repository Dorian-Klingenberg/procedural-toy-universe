# Agent session bootstrap

Use this common sequence regardless of agent provider:
1. Read README.md and AGENTS.md.
2. Read docs/VISION.md, docs/ARCHITECTURE.md, docs/ROADMAP.md, docs/ASSET_POLICY.md.
3. Check current files, git status, recent commits, and issues if available.
4. Identify what is established versus still a proposal.
5. Return: **Current state**, **non-negotiable invariants**, **open decisions**, **proposed next small task**, **verification plan**.
6. Wait for user approval before modifying the repository.

When asked to implement, use a focused branch/PR when practical, include tests or validation evidence, and avoid unrelated changes.
