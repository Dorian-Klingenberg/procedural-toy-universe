# Asset and intellectual-property policy (draft)

The goal is a genuinely redistributable, original project.

- Publicly downloadable does **not** mean open licensed.
- Do not include Star Wars names, logos, models, textures, sounds, or other franchise-specific media as bundled content without documented authorization.
- Do not copy Planet Coaster code or assets; its modular editor is only a design inspiration.
- Prefer original assets or clearly licensed CC0 content for initial prototypes.
- Review licenses and attribution obligations for each asset, including dependencies and textures.
- Record source URL, creator, license identifier/version, retrieval date, modifications, and attribution in an asset manifest before committing any third-party content.
- Separate engine/code license from content licenses. The project's code license is not selected yet.
- Do not imply that a fan-made model is free of third-party IP rights simply because the uploader grants a license.
