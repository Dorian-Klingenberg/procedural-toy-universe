# GH-600 study companion

This directory organizes preparation for the [GitHub Certified: Agentic AI Developer](https://learn.microsoft.com/en-us/credentials/certifications/agentic-ai-developer/) certification, Exam GH-600: Developing in Agentic AI Systems.

See the [training hub](../README.md) for the cross-certification study sequence, shared Responsible AI practices, and links to the [AI-103](../ai-103/README.md) and [AI-500](../ai-500/README.md) tracks.

## Start here

- [Test me later](TEST_ME_LATER.md) — automatically maintained revisit queue for
  confusing wording, prerequisites, and shaky concepts.
- [Progress memory](../PROGRESS.md) — shared record of understanding,
  experiments, and useful next moves for a future dashboard.
- [Inspiration resources](INSPIRATION_RESOURCES.md) — public GitHub examples,
  question prompts, and GH-600-specific blindside watch.
- [Official GH-600 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/gh-600) — current exam scope.
- [Certification overview](https://learn.microsoft.com/en-us/credentials/certifications/agentic-ai-developer/) — current certification information.

Start here by talking through what you already know. The live official guide is
the source of current exam scope; this directory intentionally does not copy it
into a fixed local curriculum. Follow a prerequisite, an experiment, or an
AI-103/AI-500 connection whenever it makes the current GH-600 idea clearer.
