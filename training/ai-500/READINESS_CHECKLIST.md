# AI-500 readiness checklist

- **Status:** Starter checklist; objective-by-objective mapping is not yet complete.
- **Exam focus:** Designing and implementing multi-agent AI solutions.
- **Authoritative source:** [Official AI-500 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-500). Recheck the live guide before each study cycle.

## Preparation

- [ ] Review the current official study guide and record its update/review date.
- [ ] Map every current official objective to a learning resource, a practice activity, and evidence; keep the official guide as the source of truth.
- [ ] Identify which objectives require hands-on multi-agent, Azure, or Microsoft Foundry practice and which can first be explored through discussion or a mock exercise.
- [ ] Define a bounded hands-on environment, identity and permission boundaries, data-handling rules, and spending limits before creating resources. See [Q-012](../../docs/OPEN_QUESTIONS.md).
- [ ] Use synthetic or otherwise approved data in prompts, agent state, evaluation sets, logs, and traces.
- [ ] Complete and retain hands-on evidence for applicable design, implementation, evaluation, monitoring, security/governance, and deployment objectives as described by the current guide.
- [ ] For multi-agent exercises, record agent responsibilities, tool boundaries, coordination/handoffs, observable results, failure handling, and human review points where relevant.
- [ ] Apply the [shared Responsible AI checklist](../README.md#shared-responsible-ai-practice-checklist) and note the evidence that supports each relevant practice.
- [ ] Label each item of evidence as **hands-on**, **mock**, or **discussion/design**; do not count a proposal as an implementation.
- [ ] Record remaining gaps and choose one bounded next study task.
