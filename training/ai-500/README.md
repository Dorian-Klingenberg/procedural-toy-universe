# AI-500 study track

This directory organizes preparation for [Exam AI-500: Designing and Implementing Multi-Agent AI Solutions](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-500).

## Start here

- [Test me later](TEST_ME_LATER.md) — automatically maintained revisit queue for
  confusing wording, prerequisites, and shaky concepts.
- [Progress memory](../PROGRESS.md) — shared record of understanding,
  experiments, and useful next moves for a future dashboard.
- [Inspiration resources](INSPIRATION_RESOURCES.md) — public multi-agent
  examples, question prompts, and AI-500-specific blindside watch.
- [Certification training hub](../README.md) — GH-600-first starting point,
  shared Responsible AI practices, and cross-track connections.
- [Official AI-500 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-500) — authoritative source for current exam objectives.

## Related tracks

software-engineering, or operational context. A later Foundry micro-lab can
stay under `training/` and use the learner's authenticated lab environment
with credentials and endpoint values kept only in Git-ignored local files.

Use AI-500 as a deep companion to GH-600 and AI-103 when multi-agent or
software-engineering ideas make the current topic clearer. It is not reserved
for the end of a fixed study sequence.
