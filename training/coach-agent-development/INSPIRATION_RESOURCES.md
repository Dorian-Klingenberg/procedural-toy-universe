# Certification Learning Coach inspiration shelves

Each certification has its own inspiration shelf. The tutor uses the shelf for
the track currently being discussed, so GH-600 examples do not accidentally
become AI-103 or AI-500 guidance.

| Certification | Inspiration shelf | Typical use |
|---|---|---|
| GH-600 | [GH-600 resources](../gh-600/INSPIRATION_RESOURCES.md) | GitHub Copilot agents, customizations, tools, MCP, workflows, and practice-lab ideas. |
| AI-103 | [AI-103 resources](../ai-103/INSPIRATION_RESOURCES.md) | Azure AI and Foundry learning labs, fair practice questions, and application-level experiments. |
| AI-500 | [AI-500 resources](../ai-500/INSPIRATION_RESOURCES.md) | Multi-agent architecture, orchestration, evaluation, operations, security, and deployment depth. |

Every shelf is optional inspiration, not a fixed curriculum or a substitute for
the live official study guide. Each also contains a **blindside watch** for
things likely to be missed by a learner who only follows the obvious path.
