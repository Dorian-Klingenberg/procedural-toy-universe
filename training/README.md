# Certification training hub

This is a learning lab for GH-600, AI-103, and AI-500. Start with GH-600.
Use AI-103 when Azure application and agent practice helps, and bring in AI-500
whenever multi-agent or software-engineering ideas make the current topic more
understandable. The paths are connected; they are not a fixed curriculum.

The current official study guide for each certification is the source of exam
scope. The tutor should revisit it as the learner studies, then identify missing
prerequisites, deeper ideas, and unfamiliar question wording. Passing through a
document once is not the same as understanding it.

## How this lab works

- Talk through ideas in plain language, then connect them to certification
  vocabulary and question styles.
- Build small, disposable programs under `training/` when making something is
  the clearest way to learn.
- Let the tutor automatically collect topics to revisit, especially confusing
  wording, shaky prerequisites, and misconceptions.
- Keep a light [progress memory](PROGRESS.md) of what has been explored,
  current understanding, experiments, and useful next moves. It is structured
  for a future dashboard, not a study-completion bureaucracy.
- Use both relaxed in-conversation questions and occasional mini-assessments.
- Use official or authorized sample material when available. Tutor-authored
  questions are original practice, not real exam questions.

The track documents are useful starting points, not a contract that forces a
particular study order or an evidence bureaucracy. Keep what helps; revise the
learning path as understanding grows.
